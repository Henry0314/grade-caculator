如何公開網頁給同學使用？（免費 3 大方法）

方法 1 最推薦 GitHub Pages（免費、永久有效）
  1. 在 GitHub 建立一個公開倉庫 (Repository)。
  2. 將這份檔案命名為 index.html 上傳。
  3. 到儲存庫的 Settings → Pages，選擇分支為 main 儲存。
  4. 約 1 分鐘後就會獲得公開網址（如 https://帳號.github.io/專案名），直接傳給同學即可！
方法 2 最快速免註冊 Netlify Drop / Vercel

打開 Netlify Drop，將裝有 index.html 的資料夾直接拖曳進去，10 秒內立即產生專屬公開網址。

方法 3 班級通訊軟體 直接傳檔案

將此檔案儲存為 及格試算器.html，直接傳到 Line 班群或 Discord，同學用手機或電腦點擊皆可直接在瀏覽器離線開啟！
